Standardseite

Eigene HTML-Seite für unbekannte Domains und vorübergehend nicht erreichbare Dienste.

404 / 502 / 503 / 504
Anzeige: Unbekannte HTTP-Domains erhalten die Standardseite mit HTTP 404. Für konfigurierte Domains mit nicht erreichbarem Backend wird sie bei HTTP 502/503/504 gezeigt. Ein unbekannter HTTPS-Hostname benötigt weiterhin ein passendes TLS-Zertifikat, sonst erscheint zuerst eine Browserwarnung. DNS und Router müssen auf ProxyCircuit zeigen.
