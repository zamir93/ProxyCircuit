# Mitarbeit / Contributing

1. Issue ohne Produktionsdaten anlegen und Änderungen nachvollziehbar beschreiben.
2. Änderungen in eigenem Branch, Tests ausführen: `python -m pytest -q`.
3. Bei Änderungen an Nginx-Generator, TLS oder Zertifikatsspeicher zusätzliche Regressionstests ergänzen.
4. Keine privaten IP-Topologien, Passwörter, Schlüssel oder Kopien produktiver SQLite-Datenbanken committen.
5. Quellcode-Lizenzierung ist **noch nicht festgelegt**; externe Codebeiträge bitte zuvor mit dem Rechteinhaber abstimmen.
